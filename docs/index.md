# Biblioteca de prompts de IA

Esta colección está pensada para guardar prompts reutilizables en formato Markdown y publicarlos sin necesidad de crear una aplicación web compleja.

## Categorías

- [Programación](prompts/programacion/README.md)
- [Investigación](prompts/investigacion/README.md)
- [Escritura](prompts/escritura/README.md)
- [Análisis de datos](prompts/analisis-de-datos/README.md)
- [Productividad](prompts/productividad/README.md)

## Cómo usar esta biblioteca

1. Añade un archivo `.md` dentro de la carpeta correspondiente.
2. Usa un formato claro con objetivo, contexto y salida esperada.
3. Mantén cada prompt reutilizable y fácil de copiar.
4. Cuando quieras publicar cambios, ejecuta `mkdocs build` y genera el sitio estático.

## Estructura sugerida

```text
docs/
  prompts/
    programacion/
      README.md
      analisis-codigo.md
    investigacion/
      README.md
      resumen-investigacion.md
    escritura/
      README.md
      redaccion-contenido.md
    analisis-de-datos/
      README.md
      analisis-dataset.md
    productividad/
      README.md
      planificacion-diaria.md
```

Este enfoque permite mantener un repositorio de prompts en Markdown, con navegación y clasificación sin administrar un sitio dinámico completo.
