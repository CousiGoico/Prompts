# Limpieza y análisis

## Prompt

```markdown
Actúa como analista de datos senior. Revisa el siguiente conjunto de datos y ayúdame a obtener conclusiones útiles y accionables.

Contexto:
- Tipo de dato: [métricas, CSV, informes, encuestas, logs]
- Objetivo: [qué quieres descubrir o mejorar]
- Variables relevantes: [indica columnas o campos importantes]

Tareas:
1. Identifica problemas de calidad: valores nulos, duplicados, inconsistencias y errores.
2. Explica qué patrones o tendencias observas.
3. Resalta métricas clave y anomalías.
4. Sugiere hipótesis razonables para explicar los resultados.
5. Propón una visualización o resumen ejecutivo para comunicarlo.

Entrega:
- Diagnóstico inicial
- Hallazgos clave
- Recomendaciones
- Resumen para presentación
```

## Cuándo usarlo

Cuando necesitas comprender un dataset, preparar un análisis y resumir resultados de una manera clara para una decisión.
