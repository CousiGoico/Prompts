## Reglas recomendadas

- Cada carpeta representa una categoría.
- Cada prompt debe vivir en un archivo `.md` independiente.
- Mantén un título claro y un bloque de instrucciones reutilizable.
- Si un prompt se vuelve complejo, añade un `README.md` con descripción y ejemplos.
