# Redacción de contenido

## Prompt

```markdown
Eres un redactor y editor experto. Tu tarea es convertir la siguiente idea en un texto claro, persuasivo y bien estructurado.

Contexto:
- Tema: [tema o producto]
- Audiencia: [tipo de lector]
- Objetivo: [informar, convencer, educar o vender]
- Tono: [formal, cercano, técnico, creativo]

Instrucciones:
1. Genera un título atractivo y claro.
2. Crea una introducción que capte la atención.
3. Organiza el contenido en secciones lógicas.
4. Usa lenguaje claro, directo y apropiado para la audiencia.
5. Añade conclusión y llamada a la acción si procede.

Formato de salida:
- Título
- Introducción
- Cuerpo principal
- Conclusión
- Versión corta para resumen o publicación
```

## Cuándo usarlo

Cuando necesites redactar un artículo, un email, una web, un post o un texto persuasivo a partir de una idea básica.
