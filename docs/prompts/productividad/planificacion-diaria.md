# Planificación diaria

## Prompt

```markdown
Actúa como un coach de productividad y ayuda a organizar mi día con foco y realismo.

Contexto:
- Objetivo principal del día: [descripción]
- Tareas pendientes: [lista]
- Tiempo disponible: [horas o bloques]
- Nivel de energía: [alto, medio, bajo]

Instrucciones:
1. Prioriza las tareas por impacto y urgencia.
2. Divide el trabajo en bloques realistas.
3. Sugiere una agenda diaria con tiempos y descansos.
4. Identifica qué puede posponerse o delegarse.
5. Indica cómo medir si el día ha sido exitoso.

Formato de salida:
- Objetivo principal
- Tareas prioritarias
- Agenda recomendada
- Riesgos o distracciones
- Criterio de éxito
```

## Cuándo usarlo

Cuando necesites ordenar tareas, crear una agenda realista o prepararte para un día cargado de trabajo.
