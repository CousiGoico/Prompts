# Síntesis de investigación

## Prompt

```markdown
Actúa como investigador y analista documental. Quiero que conviertas la siguiente información en un resumen claro, preciso y accionable.

Contexto:
- Tema: [describe el tema]
- Fuentes: [lista fuentes, enlaces o documentos]
- Objetivo: [qué quieres entender o decidir]

Instrucciones:
1. Resume el contenido principal en 5-8 puntos.
2. Destaca los conceptos clave y definiciones importantes.
3. Compara las ideas principales y señala puntos de desacuerdo.
4. Identifica implicaciones prácticas para mi caso.
5. Propón una conclusión final y 3 preguntas para profundizar.

Formato de salida:
- Resumen ejecutivo
- Ideas clave
- Diferencias y controversias
- Conclusiones
- Siguientes pasos
```

## Cuándo usarlo

Cuando tengas varios documentos, artículos o notas y necesites extraer la información útil sin perder contexto.
