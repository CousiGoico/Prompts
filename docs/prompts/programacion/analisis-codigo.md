# Análisis de código

## Prompt

```markdown
Actúa como un ingeniero de software senior y revisa el siguiente código con enfoque en calidad, mantenibilidad y robustez.

Contexto:
- Lenguaje: [indica el lenguaje o tecnología]
- Objetivo del proyecto: [describe la finalidad]
- Restricciones: [añade rendimiento, seguridad o compatibilidad]

Tareas:
1. Explica qué hace el código en pocas palabras.
2. Identifica posibles errores, bugs o riesgos.
3. Señala oportunidades de mejora en diseño o legibilidad.
4. Sugiere una versión mejorada con ejemplos concretos.
5. Indica qué pruebas deberían añadirse.

Entrega el resultado en formato:
- Resumen ejecutivo
- Problemas detectados
- Recomendaciones
- Ejemplo de refactorización
```

## Cuándo usarlo

Cuando quieras mejorar un fragmento de código, detectar errores o preparar una revisión técnica.
